# Teacher’s Day Surprise 2026

> A minimalist, coding-inspired interactive digital experience created as a special Teacher’s Day surprise.

## ✨ About

**Teacher’s Day Surprise 2026** is a small personal web project created by **Jai Verma (CodeGhost)** as a digital greeting for a teacher.

Instead of creating a traditional static greeting card, the project turns the idea into an immersive web experience with subtle 3D depth, motion, ambient lighting, and a minimalist programming aesthetic.

The experience is designed to feel elegant, personal, and thoughtful while keeping the interface intentionally simple.

## 🎨 Design

The visual identity combines a premium dark aesthetic with subtle programming-inspired elements.

The design features:

- Deep navy and near-black backgrounds
- Warm ivory typography
- Soft blue and cyan atmospheric lighting
- Subtle code symbols and snippets
- Fine grid and dotted patterns
- Layered depth and 3D effects
- Smooth cinematic transitions
- Minimalist composition with generous negative space

The coding elements are intentionally understated, keeping the focus on the Teacher’s Day message rather than turning the experience into a conventional developer-themed interface.

## ⚡ Features

- Interactive 3D visual depth
- Mouse-based parallax interaction on desktop
- Touch-friendly behavior on mobile
- Smooth entrance animations
- Ambient background motion
- Subtle coding-themed decorative elements
- Dynamic lighting and glow effects
- Responsive layout across screen sizes
- Mobile-first design
- Reduced-motion support
- Lightweight static implementation
- No backend or database required

## 🛠️ Built With

- **HTML5** — Structure and content
- **CSS3** — Styling, responsive layout, animations, and 3D effects
- **Vanilla JavaScript** — Interactivity, parallax, and dynamic effects

The entire experience is contained in a single HTML file.

## 🚀 Run Locally

No installation or build process is required.

Simply open `index.html` in a modern web browser.

For the best experience, the project can also be served through a lightweight local server such as VS Code Live Server.

## 🌐 Deployment

Because this is a static website, it can be deployed without a backend or build process.

The project is suitable for platforms such as:

- Netlify
- GitHub Pages
- Cloudflare Pages
- Vercel

The deployed URL can also be converted into a QR code, allowing the digital experience to be accessed directly from a physical Teacher’s Day card.

## 📱 Responsive Experience

The experience is designed for:

- Mobile phones
- Tablets
- Laptops
- Desktop monitors

The layout adapts to different screen sizes while maintaining the visual hierarchy, animations, typography, and overall atmosphere.

Desktop users can interact with subtle pointer-based depth effects, while mobile users receive a touch-friendly experience without depending on hover interactions.

## ♿ Accessibility & Performance

The project is designed to remain lightweight and comfortable to use.

It includes:

- Responsive layouts
- Readable typography and contrast
- Reduced-motion support
- Efficient animation handling
- GPU-friendly CSS effects
- No unnecessary frameworks
- No backend
- No database
- No API keys
